# CC 充放电曲线提取设计

日期：2026-08-03

## 目标

在 EISMaster 中增加一个独立的“CC 曲线”功能，用于读取 CHI Chronopotentiometry（CP）二进制文件，提取充电段和放电段，并按时间拼接成完整的时间–电压曲线。

## 已确认的文件规则

- 输入目录为项目根目录下的 `L` 文件夹。
- 只处理 CC/CP 文件，不处理同目录中的 EIS 文件。
- CC 文件头包含 `CP` 和 `Chronopotentiometry`；EIS 文件头包含 `IMP`。
- CC 文件包含点数、采样间隔和电压数据；当前样本的采样间隔为 0.01 s。
- 静置数据不进入最终曲线；EIS 文件也不作为静置段拼接。

## 功能范围

### 独立页面

在现有 EISMaster 中新增与 EIS、DRT 等功能并列的“CC 曲线”页面。该页面拥有独立的文件扫描、解析、预览和导出流程，不改变现有 EIS 导入、拟合和导出逻辑。

### 文件扫描

- 扫描用户选择的目录，默认支持项目根目录下的 `L` 文件夹。
- 仅接受 `.bin` 且文件内容确认是 CP/Chronopotentiometry 的文件。
- 自动跳过 EIS 文件和其他未知文件。
- 解析失败时报告具体文件和原因，不静默跳过有效 CC 文件。

### 曲线提取

- 每个 CC 文件作为一个原始充电或放电分段。
- 读取原始电压点，按文件采样间隔建立分段时间。
- 根据文件中的电流方向和电压变化方向标记“充电”或“放电”。方向不一致时报告解析错误。
- 按样品编号分组，并按电压目标和充放电方向确定拼接顺序。
- 拼接后生成连续总时间，不把静置或 EIS 数据插入曲线。
- 保留来源文件、分段编号和分段时间，便于追溯原始数据。

### 预览和导出

预览区显示完整曲线，并区分充电段和放电段。导出至少包含以下字段：

- `total_time_s`：拼接后的总时间；
- `segment_time_s`：当前分段时间；
- `voltage_v`：电压；
- `mode`：charge 或 discharge；
- `segment_index`：分段编号；
- `source_file`：来源文件。

同时导出分段汇总表，包含来源文件、方向、起止电压、点数、持续时间和拼接顺序。

## 验收标准

- L 文件夹中的 EIS 文件不会出现在 CC 曲线数据中。
- S01 等电压上升数据被标记为充电，S03 等电压下降数据被标记为放电。
- 合并曲线的总时间连续、每个点可追溯到来源文件。
- 静置数据不进入合并结果。
- 单文件解析、分段排序、时间拼接和导出均有自动化测试。
- 现有 EIS、拟合、DRT 和已有导出测试不受影响。
